# Scan Obsidian vault for tasks that could become puddle requests

List the open task lines ("- [ ]") in an Obsidian vault, with the file each came from, as candidates for puddle requests.

## For the user

The app runs on a schedule. You can also run it now from puddle with the form below.

| What to enter | Kind | Default |
|---|---|---|
| Subfolder of the vault to scan, relative to the vault root. Empty scans the whole vault. | string | empty |

**You get:** A list of open tasks, each with the task text, the vault-relative file path and the line number.

Create the model instance the workflow runs:

```bash
swamp model create @puddleworks/obsidian-task-scan obsidian-task-scan-model \
  --global-arg vaultPath=<vaultPath>
```

Run it:

```bash
swamp workflow run @puddleworks/obsidian-task-scan
```

Each result item contains `path` (relative to the vault), `line` (1-based), and trimmed task `text`.

Schedule it:

```bash
swamp workflow trigger set @puddleworks/obsidian-task-scan --schedule "0 8 * * 1"
swamp workflow trigger get @puddleworks/obsidian-task-scan
```

This example runs Mondays at 08:00. Scheduled runs need `swamp serve`; add `--input folder=Projects` to the trigger set command to limit them to a subfolder.
